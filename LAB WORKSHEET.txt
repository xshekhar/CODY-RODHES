Q5>One of these is a command that queries a system.The other is a folder of plain text files.Why does that difference matter?
Answer>A plain text folder (/var/log) stores raw, unindexed lines that any simple tool can read, but it is slow and unstandardized.
 A query command (log show) queries a compressed, structured binary database (unified logging), which is much faster, 
 saves disk I/O, enforces rich metadata (PID, subsystem), and handles privacy automatically."
